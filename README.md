# uiassgesh.github.io
Snow Gesh — социальное приложение Шерегеша

Текущая версия: V36.
Фото и кадры видео автоматически анализируются на устройстве. Чистые материалы публикуются сразу, подозрительные и непроверяемые передаются модератору. Модель хранится в приложении и кешируется после первой загрузки. Жалобы показывают медиа, материалы автора и причины решений.
