# uiassgesh.github.io
Snow Gesh — социальное приложение Шерегеша

Текущая версия: V36.
Фото и кадры видео автоматически анализируются на устройстве. Чистые материалы публикуются сразу, подозрительные и непроверяемые передаются модератору. Движок анализа загружается через jsDelivr, а сжатая модель хранится в приложении и кешируется после первой проверки. Медиа пользователя не отправляются на внешний сервер анализа. Жалобы показывают медиа, материалы автора и причины решений.
