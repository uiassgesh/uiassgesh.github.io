# uiassgesh.github.io
Snow Gesh — социальное приложение Шерегеша

Текущая версия: V40.
По запросу пользователя восстановлен прежний полноэкранный главный экран с горным пейзажем, крупным логотипом SNOW GESH, погодой, кнопкой «На гору» и круглыми кнопками разделов. Улучшения публикаций и модерации V39 сохранены: черновики, восстановление медиа после перезагрузки, этапы и отмена проверки, результаты двух медиа-проверок, история решений, уведомления и полный редактор отклонённого материала.

Публикации и объявления доступны только после входа. Автор и блокировка привязаны к постоянному логину аккаунта. Чистые материалы публикуются после автоматической проверки, подозрительные и непроверяемые скрываются до решения модератора; аккаунт автоматически не блокируется. Хранение пользовательских данных остаётся локальным в текущем браузере и не является серверной синхронизацией.

Движок анализа загружается через jsDelivr, а сжатая модель хранится в приложении. Медиа пользователя не отправляются на внешний сервер анализа. Личная переписка не сканируется: модератор получает только отправленную пользователем жалобу.
