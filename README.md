# uiassgesh.github.io
Snow Gesh — социальное приложение Шерегеша

Текущая версия: V37.
Публикации и объявления доступны только после входа. Автор и блокировка привязаны к постоянному логину аккаунта, поэтому смена отображаемого имени не снимает ограничение.
Фото и кадры видео автоматически анализируются на устройстве. Пороги передачи возможного контента 18+ модератору снижены. Чистые материалы публикуются сразу, подозрительные и непроверяемые передаются модератору. Движок анализа загружается через jsDelivr, а сжатая модель хранится в приложении и кешируется после первой проверки. Медиа пользователя не отправляются на внешний сервер анализа. Жалобы показывают медиа, материалы автора и причины решений.
